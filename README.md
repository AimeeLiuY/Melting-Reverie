# Melting-Reverie
Liu's Creative Coding A2project

https://editor.p5js.org/AimeeLiuY/sketches/ThKnPLMOW

My project is called Melting Reverie， an interactive surrealist animation inspired by Salvador Dalí's paintings.

1. Project Purpose

I have always been interested in surrealist art, and I also have a background in traditional art. Through this project, I wanted to use coding to create melting shapes and dreamlike distortion effects. My goal was to combine traditional art with computational creativity.

2. Project Features

The main features of my project are using Perlin Noise to create natural and irregular movements and adding mouse interaction. When users move their mouse, the shapes change and become distorted.

3. How to Use

Users can move their mouse to interact with the animation. The shapes will change and distort based on mouse movement. There is also a reset function to return the animation to its original state.

4. Technical Requirements

I originally planned to use Processing, but later changed to p5.js. I tested my project using Safari on my iPad. The animation runs in a web browser and uses mouse interaction.

5. Project Limitations

I originally wanted to create more complex melting animations and surrealist visual effects. However, because I am still learning coding, procedural animation, and noise functions, some effects could be improved. For example, I would like to make the melting movements smoother and improve the overall visual composition.
